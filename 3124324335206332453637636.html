⚡ 1. LINQ 高效查詢與剔除重複 (Distinct)

剔除重複資料 (LINQ Distinct & DataGridView)

#LINQ #Distinct

利用 LINQ 與 DataGridView 資料集進行關鍵字模糊搜尋以及剔除指定欄位重複值的語法。

C# / LINQ
// 1. SQL 剔除重複記錄
// Select Distinct * From myTable Where xxxx

// 2. DataGridView 模糊查詢
IEnumerable<DataGridViewRow> enumerableList = this.dataGridView.Rows.Cast<DataGridViewRow>();  
List<DataGridViewRow> list = (from item in enumerableList  
  where item.Cells[0].Value.ToString().IndexOf(this.KeyWord.Text) >= 0  
  select item).ToList();  
  
// 3. 剔除 FirstName 欄位中有重複的資料
var result = (from p in db.t_Personnel
              select p.FirstName).Distinct();

// 4. 從 DataGridView 取得不重複的欄位值 List
var distinctList = dataGridView1.Rows.Cast<DataGridViewRow>()
   .Where(x => !x.IsNewRow)
   .Where(x => x.Cells[column].Value != null)
   .Select(x => x.Cells[column].Value.ToString())
   .Distinct()
   .ToList();

📊 2. List 排序與多條件排序 (OrderBy / Sort)

多條件座標排序與字母/時間排序

#OrderBy #CompareTo

包含繪圖物件座標 OrderBy / ThenBy 雙重排序、字串字母 CompareTo 排序與 DateTime 時間排序。

C# OrderBy & Sort
// 1. LINQ 條件排序與 AddRange
var query = from module in list
            orderby module.OrderNum
            select module;
_plotlist.Clear();
_plotlist.AddRange(query);

// 2. 雙重條件座標排序 (以 Y 座標主排序，X 座標次排序)
var CurrentDevlist = CurrPOU.PGplotlist
    .OrderBy(x => x.Location.Y)
    .ThenBy(x => x.Location.X)
    .ToList<Plot>();

// 3. List<String> 按字母排列
Displayparaments.Sort((x, y) => x.CompareTo(y));
EditProject.POUList.Sort((x, y) => x.POUName.CompareTo(y.POUName));

// 4. List 按時間 DateTime 排列
StrList.Sort((x, y) => DateTime.Compare(Convert.ToDateTime(x.Value), Convert.ToDateTime(y.Value)));

// 5. Sourcelist 按關鍵字出現位置排序
Sourcelist.Where(x => x.ToUpper().IndexOf(CompStr) >= 0)
          .OrderBy(x => x.ToUpper().IndexOf(CompStr))
          .ToList();

💡 正確理解 C# Async 與非同步觀念

引用自 Life / Opass Life 觀念導正：
非同步 (Asynchronous) 不等於多執行緒 (Multithreading)。Async / Await 的本質是「讓出執行緒資源等待 I/O 完成」，而非盲目開啟多執行緒。正確區分 CPU-bound 與 I/O-bound 才能真正優化 UI 回應速度並避免 Thread Pool 枯竭。
